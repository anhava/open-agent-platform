# Supabase - @aihio/supabase

This package is responsible for managing the Supabase client and various utilities related to Supabase.

Make sure the app installs the `@aihio/supabase` package before using it.

```json
{
    "name": "my-app",
    "dependencies": {
        "@aihio/supabase": "*"
    }
}
```
